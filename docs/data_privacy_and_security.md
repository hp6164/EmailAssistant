# Data Privacy and Security Plan

Penpal ensures user data privacy and security by implementing the following measures:

- **Data Encryption**: Emails are encrypted in transit using TLS and stored using AES-256 encryption.
- **Data Access**: Penpal only accesses unread email headers and content for summarization and categorization. It does not store full email data.
- **User Privacy**: Penpal adheres to GDPR and CCPA regulations. No email content is used for external purposes.
